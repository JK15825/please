# 💕 Will You Be My Valentine? 💕

A cute mobile-friendly web app to ask someone special to be your Valentine!

## Features

- 📱 Mobile-responsive design
- 💖 Beautiful animations and transitions
- 🎨 Gradient backgrounds and floating hearts
- 📸 Place for your couple's photo
- 💝 Sweet messages and a special question
- 🎉 Celebration screen when they say yes!

## How to Use

1. **Add Your Photo**: Replace `couple-photo.jpg` with a photo of you and your special someone
   - Or just open the app and it will show a placeholder
   
2. **Customize (Optional)**: 
   - Edit `index.html` to personalize the messages
   - Edit `style.css` to change colors or styling
   
3. **Share**: 
   - Open `index.html` in a browser
   - Or host it on GitHub Pages, Netlify, or any web hosting service
   - Send the link to your special someone!

## Running Locally

Simply open `index.html` in your web browser, or use a local server:

```bash
# Using Python 3
python -m http.server 8000

# Using Python 2
python -m SimpleHTTPServer 8000

# Then visit http://localhost:8000
```

## How It Works

1. **Step 1**: A warm greeting with animated hearts
2. **Step 2**: Display a photo of you two together
3. **Step 3**: Show a list of things you love about them
4. **Step 4**: Ask the big question: "Will You Be My Valentine?"
5. **Step 5**: Celebration when they say yes!

### Fun Easter Egg 🥚

Try clicking the "Maybe..." button - it has a surprise! The button will move around and become harder to click, while the "Yes!" button becomes more appealing. 😄

## Technologies Used

- Pure HTML, CSS, and JavaScript
- CSS animations and transitions
- Mobile-first responsive design
- No frameworks or dependencies needed!
